## Implementation choices

- TypeScript, Node 22.17+, React, SQLite through Node's built-in SQLite module, and an independently compiled native filesystem helper.
- The engine is the sole authority; runtime adapters and research data cannot issue roles or approvals.
- Synchronous database transactions serialize admission; asynchronous effects have durable intents and are never retried as part of a storage retry.
- Unsupported containment and unverified runtime versions fail closed. Release certification requires actual Linux and macOS runtime evidence. Test doubles cannot certify production containment.
- Spending budgets remain deferred by the specification.

2026-09-24 context accounting milestone: actual model requests now consume the configured context budget. 2026-09-25 automatic compaction milestone: the host rebuilds authoritative model instructions independently of runtime system text. Near 70% usable context, or after a compaction request, it archives the covered conversation and asks the assigned model for a bounded, tool-free narrative. Checkpoints commit complete engine state, untrusted source lineage and exact transcript-prefix hashes together. Subsequent requests use that checkpoint plus verified new messages; changed history fails closed. The 90% optional-context gate applies before summarization. A failed attempt retains the previous checkpoint, retries once and then invalidates authority into a visible pause. The host also checks exact issued tool calls before dispatch, so an extra runtime call cannot start during compaction.
